One-line entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty.

> WARNING: This human requires 8 hours of nightly charging. Operating below 20% causes irritability, poor decisions, and spontaneous napping in meetings.

The safety warning label that should come printed on every human being, framed as a battery/charging warning: a human is a device that must be plugged in for 8 hours every night, and running it on low battery has predictable, embarrassing side effects.

## Run

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and verifies it byte-for-byte.
